# yolo-labeling-toolkit

Три скрипта, которые я использую, когда размечаю датасет для YOLO в LabelImg. Они закрывают то, на чём чаще всего теряется время: фото, повёрнутые только меткой EXIF, ручная разметка тысяч однотипных объектов и сборка архива, который потом без ошибок читается при обучении.

## Как это работает

1. **Подготовка.** `1_prepare.py` поворачивает фото по метке EXIF и сохраняет их без неё. Это важнее, чем кажется: LabelImg показывает такие фото боком, а Roboflow и Ultralytics — повёрнутыми, и после импорта рамки съезжают с объектов. Заодно скрипт кладёт рядом файл классов для LabelImg.
2. **Предразметка (по желанию).** Когда вручную размечено 80–100 фото, `2_prelabel.py` обучает на них YOLO и размечает остальные. Ручную разметку он не трогает, а список предразмеченных фото сохраняет, чтобы каждое можно было проверить глазами.
3. **Проверка и архив.** `3_check_and_pack.py` проверяет номера классов, координаты, нулевые рамки и дубли, ловит остатки EXIF-поворота и случай, когда LabelImg дописал в список новый класс и номера съехали. Рисует превью с рамками и собирает архив YOLOv8 с `data.yaml`. Если находит ошибки, архив не собирает.

## Запуск

```
pip install pillow
python 1_prepare.py папка_с_фото work classes.txt
labelImg work/images work/predefined_classes.txt work/labels
python 2_prelabel.py work          # нужен pip install ultralytics
python 3_check_and_pack.py work dataset.zip
```

`classes.txt` — список классов по одному в строке, в том же порядке, что в `data.yaml`. В LabelImg переключите формат на YOLO и включите Auto Save; классы выбирайте только из списка.

Если видеокарте не хватает памяти при предразметке, добавьте `--batch 2` или `--imgsz 960`.

## Лицензия

AGPL-3.0: предразметка использует Ultralytics YOLO, который распространяется по этой лицензии.
