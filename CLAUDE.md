# yolo-labeling-toolkit

Три скрипта для разметки датасета YOLO в LabelImg: подготовка фото, предразметка моделью и проверка с упаковкой архива YOLOv8.

## Структура

- `1_prepare.py` — поворачивает фото по метке EXIF и сохраняет без неё, кладёт список классов для LabelImg.
- `2_prelabel.py` — обучает YOLO на уже размеченных фото и размечает остальные. Ручную разметку не трогает, список предразмеченных фото сохраняет.
- `3_check_and_pack.py` — проверяет классы, координаты, нулевые рамки, дубли и остатки EXIF-поворота, рисует превью, собирает архив с `data.yaml`. При ошибках архив не собирается.

## Команды

```
pip install pillow                  # ultralytics нужен только для 2_prelabel.py
python 1_prepare.py папка_с_фото work classes.txt
python 2_prelabel.py work
python 3_check_and_pack.py work dataset.zip
```

## Правила

- Порядок классов задаётся только файлом `classes.txt` и нигде не захардкожен: от него зависят номера классов в разметке.
- Ручная разметка важнее предразметки: никакой шаг не должен перезаписывать файлы, которые человек уже проверил.
- Скрипты не должны знать ничего о конкретном заказчике или датасете.
- Автотестов нет. Изменения проверяются прогоном всех трёх шагов на небольшом наборе фото, включая фото с EXIF-поворотом.
